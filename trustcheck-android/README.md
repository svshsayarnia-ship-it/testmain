# خرید امن — Android MVP

اپ فارسی و RTL برای ارزیابی ریسک خرید از فروشگاه‌های اینستاگرامی.

## ورودی‌ها
- آیدی اینستاگرام (`@shop`)
- لینک پروفایل
- لینک پست/ریلز (تلاش برای حل شناسه از متادیتای عمومی)
- QR Code
- Share مستقیم از اینستاگرام یا هر اپ دیگر

## سیگنال‌های نسخه 0.1
- تلاش best-effort برای دریافت تعداد فالوور از متادیتای عمومی اینستاگرام
- نسبت فالوور به میانگین لایک و کامنت برای شناسایی الگوی تعامل غیرعادی
- تناقض بین سابقه ادعایی و سال ساخت/Join اکانت
- تعداد تغییر نام کاربری
- تعداد گزارش منفی شناخته‌شده برای شماره/هویت
- قدمت دامنه از RDAP عمومی در صورت پشتیبانی رجیستری
- پرداخت فقط کارت‌به‌کارت
- قیمت غیرعادی پایین
- تصاویر تکراری/کپی (در این نسخه به‌صورت Evidence دستی)
- احراز هویت مثبت به‌عنوان سیگنال کاهنده ریسک

## اصل مهم
اپ هیچ‌وقت صرفاً با یک سیگنال، فروشنده را «کلاهبردار» اعلام نمی‌کند. اگر داده کافی نباشد، خروجی `داده ناکافی` نمایش داده می‌شود.

## محدودیت‌های واقعی نسخه 0.1
Instagram API اطلاعات خصوصی ثبت‌نام، ایمیل ورود، تاریخ دقیق ساخت همه اکانت‌ها یا فهرست کامل فالوورها را عمومی نمی‌کند. دریافت سیگنال عمومی نیز ممکن است در بعضی شبکه‌ها/اکانت‌ها توسط Instagram محدود شود. اپ در این شرایط داده جعلی تولید نمی‌کند و از کاربر Evidence اختیاری می‌گیرد.

گزارش‌های جمعی آنلاین، Phone Reputation Graph، OCR اسکرین‌شات About this account و تطبیق تصویر در وب برای نسخه سروری بعدی در نظر گرفته شده‌اند و در این APK به‌صورت خودکار فعال نیستند.

## Build
GitHub Actions روی شاخه `trustcheck-android` تست‌ها را اجرا و `app-debug.apk` را به‌عنوان artifact می‌سازد.
